PRD — Portfolio personnel de Stanislas N'doua

Nom du projet : Portfolio — Stanislas N'doua
Type : Site portfolio personnel One Page
Profil : Jeune Vibe Coder / Développeur web
Langue principale : Français
Design : Dark / Modern / Tech / Premium
Responsive : Mobile, tablette, laptop, desktop et grands écrans
Objectif principal : Présenter Stanislas, ses compétences et ses réalisations afin de donner envie à un visiteur de le contacter.

1. Vision du produit

Le site doit être le portfolio personnel professionnel de Stanislas N'doua, jeune Vibe Coder spécialisé dans la création de solutions web modernes.

L'expérience doit reprendre l'esprit de la hero section fournie :

fond sombre premium ;
identité visuelle bleu nuit / violet ;
typographie moderne et très lisible ;
grands titres ;
gradients violets/bleus ;
éléments lumineux subtils ;
portrait de Stanislas comme élément visuel principal ;
cartes flottantes de type code ;
animations légères ;
navigation simple ;
excellente lisibilité ;
design professionnel sans surcharge.

Le site doit donner immédiatement l'impression :

« Voici un jeune développeur moderne qui sait transformer une idée en produit web. »

2. Objectifs du site
Objectif principal

Présenter Stanislas N'doua et transformer les visiteurs en personnes intéressées par son travail.

Objectifs secondaires

Le site doit permettre de :

présenter son identité ;
expliquer son profil de Vibe Coder ;
présenter ses compétences ;
montrer ses projets ;
présenter son approche de travail ;
permettre de télécharger son CV ;
permettre de le contacter facilement ;
créer une présence professionnelle en ligne ;
servir de lien à partager sur LinkedIn, WhatsApp, CV, réseaux sociaux, etc.
3. Public cible

Le site s'adresse principalement à :

👨‍💼 Recruteurs

Personnes cherchant un développeur junior ou un profil tech.

🏢 Entreprises

Entreprises souhaitant développer :

un site web ;
une application ;
un outil interne ;
une solution métier ;
un MVP.
👨‍💻 Développeurs / professionnels IT

Personnes intéressées par son parcours et ses projets.

🚀 Entrepreneurs

Personnes ayant une idée et recherchant quelqu'un capable de la transformer en application.

11. Portrait

Le portrait fourni par l'utilisateur doit être utilisé comme élément central de la hero.

Le traitement visuel doit conserver une apparence professionnelle.

Traitement recommandé
détourage propre ;
suppression du fond original ;
léger contraste ;
légère correction colorimétrique ;
intégration avec le fond sombre ;
halo violet/bleu derrière le personnage ;
éventuellement légère ombre ;
aucun effet excessif.

Le personnage doit rester le point focal visuel.

25. Responsive Design

Le site doit être conçu mobile-first.

Mobile

Largeur :

320px → 767px

La hero devient verticale :

Navbar

Texte
↓
CTA
↓
Portrait
↓
Code card
Tablet
768px → 1023px

Le layout peut rester en deux colonnes lorsque l'espace le permet.

Desktop
1024px → 1439px

Hero complète en deux colonnes.

Large desktop
1440px+

Le contenu doit rester centré.

Il ne faut surtout pas étirer le contenu sur toute la largeur.

Utiliser par exemple :

max-width: 1280px;
margin: auto;
26. Règles UX importantes

Le site doit respecter :

Lisibilité

Le contraste texte/background doit être suffisamment élevé.

Navigation

La navigation doit être immédiatement compréhensible.

Cohérence

Les boutons doivent avoir les mêmes styles partout.

Espacement

Éviter les sections surchargées.

Hiérarchie

Chaque section doit avoir :

Sous-titre

Accessibilité

Prévoir :

labels pour les champs.

28. Performance

Le site doit être rapide.

Objectifs :

images optimisées ;
lazy loading pour les images hors écran ;
CSS optimisé ;
JavaScript minimal ;
éviter les animations lourdes ;
éviter les vidéos en arrière-plan ;
utiliser des formats modernes comme WebP/AVIF lorsque possible.
